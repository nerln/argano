argano

Drop a video that will not play

argano walks the raw bytes of a recording that was cut short, finds the frames, rebuilds the index and writes a copy that plays. The picture and the sound are carried across as they are, so nothing is encoded again and the original stays where it is.

MP4, MOV and M4V, from a phone, a camera, a drone or a screen recorder.

Most repairs need a second video

A file that was never finalised has lost the part that says how the picture was encoded. argano cannot invent those settings, so it reads them from a working video instead: any clip made by the same camera or the same app, at the same recording setting. That clip is called the reference. Three seconds of it is enough, and it is only read, never changed.

You will be asked for one only if this file needs it.

This window cannot open a file picker, so the location has to be typed or pasted.
