This browser cannot run the repair

The whole repair happens on this page, which asks the browser for two things: reading a file from your disk as bytes, and loading JavaScript modules. Firefox, Chrome, Edge and Safari have done both since 2018. There is no version of this that sends your video somewhere else to be repaired instead.

Your video is still in there.

A recording cut short by a dead battery, a full card or a crash keeps every frame. What it lost is the index that tells a player where each one starts. argano writes that index back, here in your browser.

Drop a video that will not play

MP4, MOV and M4V, from Photo Booth, a phone, a camera, a drone or a screen recorder.

  • Never uploaded

    The file is read on your computer. Once the page has loaded you can switch the network off.

  • Nothing encoded again

    The picture and the sound are carried across byte for byte, exactly as they were recorded.

  • Free and open source

    MIT licence, and a command line version for repairing a folder at a time.

How a repair goes

  1. 1

    Drop the file

    argano looks inside it and tells you what is wrong before it does anything.

  2. 2

    Add a clip, if asked

    Most files need three seconds of video from the same camera or app, recorded at the same setting. It is only read.

  3. 3

    Save the copy that plays

    Your original stays exactly as it was. The repaired copy is a new file.

Photo Booth recordings

Photo Booth on macOS can leave a long recording that will not open, and that is the file argano was first written for. Photo Booth keeps its settings out of the video, so a repair always asks for a reference: record three seconds in Photo Booth on the same Mac, at the same size, and give argano that clip.

Nothing leaves your computer

Your browser reads the file from your disk and hands the bytes to the code on this page. No server sees them and there is no account. Open the network panel while a file repairs and you will see no request go out.

The page sends one anonymous count when it opens, and one more only if you answer the question at the end. Neither carries anything from the video. Privacy policy

What it cannot do

  • It cannot bring back media that was never written. If the recorder stopped before the bytes reached the disk, they are not in the file, and no tool can find what is not there.
  • It does not encode anything again. Frames that were recorded badly come back exactly as badly as they were recorded.
  • It reads H.264 and H.265 video with AAC sound. Anything else is named on the diagnosis screen and goes no further.
  • It reads MP4 and MOV files, M4V included. Not MKV, not AVI, not a camera's own raw format.

The code is on GitHub: github.com/nerln/argano
